## Context

Explored all raw data and the generator code. The data simulates realistic degradation curves (power-law over 5-13 days), false-alarm spikes (4-10 readings), and sensor dropouts (~0.4% NULLs). Each of the 5 failure modes has a distinct multi-channel sensor signature. The ML model needs features that capture gradual trends while filtering transient spikes.

## Implementation Plan — 4 objects in `PREDICT_MAINT_DB.ANALYTICS`

### 1. `ASSET_SENSOR_STATS` (Dynamic Table, lag 30 min)
Hourly and multi-hour rolling statistics per asset. This is the core feature table for ML.

**Features per asset per reading:**
- **Rolling means & std**: vibration, temperature, current, RPM over 1h (2 readings), 6h (12), 24h (48), and 7-day (336) windows
- **Rate of change**: difference between current reading and 1h-ago / 6h-ago values for each sensor
- **Baseline deviation**: `(current_value - baseline) / baseline` using ASSETS table join
- **Threshold breach flags**: binary flags for alert/alarm crossings on vibration and temperature
- **Running breach count**: count of alert-level breaches in the trailing 24h window
- **Null/dropout indicator**: binary flag when any sensor channel is NULL (sensor health signal)

### 2. `ASSET_HEALTH_SUMMARY` (Dynamic Table, lag 60 min)
One row per asset — latest health snapshot for dashboards and alerting.

**Columns:**
- Latest reading timestamp and values
- Current 24h rolling mean for each sensor
- Current baseline deviation %
- Active alert/alarm status (NORMAL / ALERT / ALARM)
- Hours since last maintenance (from WORK_ORDERS)
- Count of corrective work orders in last 30 days

### 3. `PRODUCTION_OEE` (Dynamic Table, lag 60 min)
OEE metrics computed from production log, per asset per shift.

**Columns:**
- Availability = (planned - breakdown - PM) / planned
- Performance = (total_units * ideal_cycle) / (run_time * 60)
- Quality = good_units / total_units
- OEE = Availability * Performance * Quality
- 7-day rolling OEE average

### 4. `MAINTENANCE_COST_SUMMARY` (View)
Aggregated maintenance cost view per asset — joins work orders with assets.

**Columns:**
- Total corrective/preventive/inspection costs and counts
- MTBF (mean time between failures) estimate
- Average repair time and parts wait time
- Spare parts availability flag from SPARE_PARTS
